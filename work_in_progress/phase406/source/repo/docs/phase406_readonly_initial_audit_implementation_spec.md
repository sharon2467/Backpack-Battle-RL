### Physical and decoding gates

read_regular(path,pin,cap,io) validates descriptor strict types, safe canonical path and ancestor links, lstat ordinary/nlink1 before content; opens O_RDONLY|O_NOFOLLOW|O_NONBLOCK to avoid special-node blocking after a path race, fstat type/link/identity before read, bounded reads, then fstat/lstat identity after. SHA/size exact. It records path, byte pin and identity and no file contents in IO log. It never calls a SUT. End-of-job rereads only already consumed approved files for byte identity, recording this separately from semantic decode.

Strict JSON rejects duplicate keys, nonfinite numbers, invalid UTF8; JSONL requires object rows/nonblank lines, bounded line/row/total sizes and physical increasing sequence within four observer channels. Prefix/suffix semantic projections are not made. All12 are decoded once, no dynamic schema import. Source caps are copied as source literals from actual391AST; overall256MiB, record2MiB, clock64MiB/200000, observer300000; UI retains its source8MiB/65536row/16KiBrow caps. Audit validates only shapes it consumes; it never labels entire schema accepted.

Raw records carry original file/line/sequence/JSON pointer and typed values. indexes are provenance-only dictionaries of actual records, not model alias/runtime objects. Fixed expected fixture/slot plan is extracted from exact391 schema source at author generation time (AST literals, no module execution). No extra original source dependencies beyond40541 are opened.
