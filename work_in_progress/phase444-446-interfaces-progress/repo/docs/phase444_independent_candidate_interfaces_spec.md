# Phase444 independent candidate interface controls

## 1. Requirements

Test only the new phase443 pure-input interfaces using the sealed phase441 INPUT bundle. Preserve all earlier Source and results. The one permitted batch is bounded to 15 seconds and stops at its first unexpected failure; no repair/retry occurs in this batch. No full battle, activation, frame advancement, EXPECTED, original capture, native process, pool, or old control suite is permitted.

## 2. Design

Before imports, verify the sealed candidate freeze and all 15 files, plus the accepted INPUT bundle SHA. Import only the staged candidate in an isolated Python process. An open audit limits repository reads to those files and new control artifacts; record actual accesses. A profile hook counts model/component calls and rejects run/step/activation/result/primitive draw entry before execution. No helper status is presented as a native return observation.

Use one successful engine instance and its 365-record Tape. Two failed constructor attempts exercise None and SeededRandom rejection before Item/Character construction. Execute prepare once, requiring zero Tape consumption. Subsequent tests intentionally mutate this single synthetic control instance (local Timer starts and ended/winner setup); they cannot be mistaken for a real fight or observed terminal state.

## 3. Realize

`main`: verify source/input pins; install read and call monitors; import candidate; validate actual DTO; execute a finite set of single-defect copies (shape, scalar type, duplicate identity/order, topology/config/private/P7O5 and DTO convenience mismatches). Construct and inspect 33 distinct Timer objects, all 78 processing rows, sparse paths/positions, and unique Util/Game ordinary memberships. Preserve same-instance identifiers.

`reject`: expect ValueError for a named new-interface negative and record its message; any other exception or acceptance stops the batch. `state_digest`: traverse the engine's stored object graph, preserving references and float bits, to detect snapshot changes including dirty group state, callbacks, histories, Tape and caches. `check_snapshot`: compare two getter results and full stored-state digests before/after.

Prepare exactly once. Check off-clock snapshots and temporarily perturb Tape position to exercise its prepared-state guard, then restore. Test King states 0/1/2 and withNextEvent through the real history call using a forwarding spy; deliberately remove the visual-tail state table during these local calls so accidental tail access fails. Restore the table after the check.

Test Timer.start argc0, INT14/3/1 and REAL14.0 through the real wrapper/component and inspect typed before/after traces; reject BOOL and argc2. Stop each tested timer. Start the four auxiliary timers, set a clearly synthetic ended/winner fixture, invoke finish once, and forward-spy real component stops to require all four object identities in P/O and battleRage/autoRage order. Verify stopped actual state and no synthetic auxiliary-stop records.

Call the changed EngineFrameDriver.snapshot wrapper without advancing the driver, requiring its actual unadvanced counters, 33 business timers, absence of full_fx, and no mutation. Its existing stage label is recorded as a wrapper-selected label, not evidence of an actual cleanup/final frame cut. Actual five-cut native equivalence is not claimed. Existing core EOF/trailing/activation-death controls are not replayed.

`finally`: save PASS or first failure, executed case prefix, exact profiled calls, read ledger, input/source identities and explicit zero forbidden counts; seal output owner. Require the unique output directory to be absent. Freeze this script and SPEC before execution.

All listed interface controls pass in one batch; no unexpected access, forbidden call, source drift or hidden retry. Require 1 successful engine, 3 constructor attempts, 1 prepare, 1 synthetic finish, 0 frame passes, 0 Tape draws, 0 run/result/activation calls. Read the accepted bundle once; no original12 or EXPECTED. A PASS supports the tested interface boundary only. B1 cache/native prepare equivalence and B5 required output mapping remain open; B2 requires its separate finite Source review. King/formal75/full-engine admission and same-seed/global-generator equivalence remain unclaimed.
