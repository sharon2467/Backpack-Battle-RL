## 2. Design

One standard-library-only module `tests/phase438_character_initial_overlay.py` contains typed structural validation and a fixed-rule projection. Its source context is pinned by literal size/SHA in the module. The context pins the source report, all815 original project scripts,19 Character/Player/Opponent scene dependencies,359 executed Character/Util,391 observer/collector and fixed A fixture sources. It records the actual input descriptors; caller-provided booleans or replacement source manifests are not proof parameters.

`run(output_new)` verifies physical ordinary files and every Source hash, then reads only pinned437 audit, observer7-input bytes (parsing only lines1/4), and king-input-facts JSON (using only the invu P/O entries). It validates Source identity and records premises; it does not perform native Timer inference. `project(audit, bindings, ledger)` is a pure helper for independent counterexample testing; the actual I/O entry never accepts caller-supplied in-memory evidence.

The Source theorem is the implementation-side report: declarations false/null; finite seven writer-call receivers unavailable before first parent-ready; first parent-ready timer birth; every earliest later makeInvulnerable must see false and hit counted timer_before(start) before native start/true; observer counters increment before fixture gating, are monotonic and cannot be reborn; actual starts0 at pre_activate therefore covers both cuts. Generic Table.fill is reached only on ItemBook descriptor properties, Character has no generic setter, scene tracks do not target either field. Public stopped/time_left and the label private_provenance are not premises.

The exact original INPUT IDs are P47611/invu47767 and O84805/invu84961; game4015. Source_resources, Character nodes, invulnerability Timer nodes, ledger owner/timer and current/birth IDs must agree bijectively across both cuts. Raw bool and int are distinct, and duplicate JSON/object/row keys fail closed. Timers must have class Timer and the original role/path/name; birth role is null and current/checkpoint roles are invu:P/O. Missing or nonzero counters reject. Counter facts are generated at the entry to activateItems by the pinned observer, not after activation.

Output goes exclusively to a nonexistent absolute directory below repo/data. A failure before reservation writes nothing; a failure after reservation preserves created files and adds first-error.json. The report is a deepcopy of437 with exactly eight rows updated and counts1289DIRECT+10SOURCE_DERIVED+64MISSING; excluded records and all other required rows remain byte-equivalent under canonical typed JSON. Full-reference counts are updated to1391DIRECT+14SOURCE_DERIVED+74MISSING with previous437 counts retained separately. Prior exact row payloads remain in per-target provenance. Events/logs/RNG/timing/terminal strict channels are untouched.

## 3. Realize

- `require(condition, reason)`: raise Rejected on failure.
- `strict_json(raw)`: UTF-8 decode; reject duplicate keys and all nonfinite numbers/constants.
- `same(a,b)`: compare canonical JSON, retaining bool-versus-int distinctions.
- `key(row)`: require three string identity fields; return field/phase/role tuple.
- `physical(path, regular=True)`: lstat ancestors; reject symlinks and nonordinary/multilink files.
- `read_pinned(descriptor, io)`: open O_NOFOLLOW, stable identity/size/hash before/after; bounded reads; record descriptor.
- `validate_source(context, io)`: require exact context schema/counts, fixed source/input descriptor domains, verify815 script and19 scene file sets/pins plus observer/fixture/report pins; return actual Source provenance with explicit theorem premises. No proof boolean input.
- `validate_audit(audit)`: require profile437, exact1363/116 arrays, unique row keys, typed proof states/counts, eight exact missing targets, and64 remaining missing Timer.private_left rows; return target ordinal map. The actual saved artifact hash fixes full identities/order.
- `validate_cuts(records)`: exactly two checkpoint records with known sequence/site/edge/stamp, game ID, typed environment and cross-cut monotonic frame/time phase; join source_resources and character/timer nodes; enforce IDs and unique native IDs/roles. Return exact pointers and identity bindings; do not consume target-field values even if extras exist.
- `validate_ledger(facts, bindings)`: check schema and exact invu entries, typed lineage starts/stops0, ready kind, birth/current node IDs/configuration/owner bijection, and current timer identity against pre_activate cut. Return raw lineage/current evidence plus pointers. No inference from public Timer values.
- `project(audit, bindings, ledger)`: validate all arguments, deepcopy audit, change exactly the8 target dictionaries to SOURCE_DERIVED/SUPPORTED with typed false/null plus exact evidence/rule/premises, update counts and limits, assert every non-target/excluded record preserved; return report and proof.
- `save_new(path,value)`: O_EXCL/O_NOFOLLOW create, fsync and pinned readback.
- `run(output_new)`: verify literal-pinned context and Source, input pins and typed data; invoke pure helpers once; reserve new data directory only after validation; save proof/report/readback/owner. A pre-read/post-read source/input pin check records preservation; no mutable boolean release gate.
- `main(argv=None)`: require `--output-new`; call run; CLI success only means saved candidate report, never acceptance.

Author work is source creation plus compile-only. Independent reviewer should inspect actual adapter/source context before import and run one necessary new control process. Positive helper controls must produce exactly eight candidate changes, preserve all remaining required/excluded rows and old two derivations, and retain full1363 order. Specific Source challenge must address parent-ready ledger window and partial/reentrant makeInvulnerable call. No generic `source_closed=True` or similar boolean can unlock an actual run.
