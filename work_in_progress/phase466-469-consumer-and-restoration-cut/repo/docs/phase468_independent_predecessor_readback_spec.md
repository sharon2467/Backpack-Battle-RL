## 3. Realize

The source file is tests/phase468_independent_predecessor_readback.py. CLI requires `--config`, `--config-sha256` and `--output-new`; no --plan, restore or READY option exists.

- `stable(path)`: reject linked/nonregular/multiple-link control files; open O_RDONLY|O_NOFOLLOW and compare lstat/fstat signatures before/after. Return exact raw bytes and identity/mode/mtime. Critical state/manifest reads use it.
- `descriptor(row)`: strict path/size/SHA shape, resolve relative paths only against this repository, verify actual stable bytes. Root request descriptor hashes are mandatory, never computed as substitute expectations after inspection.
- `relocate(path,mapping)`: explicit longest-free single prefix association; reject ambiguous mappings. Used only for recorded predecessor/proof paths.
- `compare(actual,expected,label)`: exact nested equality; on mismatch preserve the label and first differing path/field, never normalize keys, discard metadata or retry.
- `readback(request,report)`: verify the fixed source freeze and all supplied evidence descriptors; check restore owner covers actual receipt without assuming its textual success proves restoration. Acquire the existing lock; check failed state and process references; validate saved controls, prior bundle/proof and all full trees; validate old patch/marker and78 preimages; repeat process/critical-state checks; return independent physical-readback PASS with READY still pending.
- `main`: create unique local report directory, pin config and Source, load only frozen compaction Source, apply read/write guard, invoke once after future release, retain progress/counters and first exception, verify Source unchanged, seal result/owner. A failure stops without restore, cleanup or retry. Reading or hashing files is reported separately from native/model calls.

Source preparation performs one compile-only check, no import or helper execution. The exact postcapture Root request remains absent until real paths and hashes exist. No synthetic whole-Game fixture or old restoration suite is required for this narrowly reused readonly path.
