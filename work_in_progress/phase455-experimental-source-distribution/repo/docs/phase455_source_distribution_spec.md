No captured outputs/EXPECTED or original Game code/assets enter the package. manifest.json inventories15 exact code files plus documentation/examples/lineage/verifier, all relative paths, sizes, SHA256 and kinds. Manifest excludes itself to avoid circular hashing; external owner pins it. A trusted manifest SHA can be supplied to the verifier.

Optional verify_manifest.py is a tiny stdlib-only read-only byte verifier. It imports no engine/provider, checks manifest schema/exact15 Source set, safe relative paths, no symlink in in-package parent chain, ordinary regular file with nlink1, exact bytes/hash and stable before/open/after identities. It checks listed files only, so generated outputs/pycache do not become Source payloads. It does not run/help/import/compile a battle. Local manifest agreement detects drift; authenticating the manifest requires its independently published SHA.
