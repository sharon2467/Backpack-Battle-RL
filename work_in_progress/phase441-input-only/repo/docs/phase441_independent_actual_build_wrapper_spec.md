## Requirements

## Design

`tests/phase441_independent_actual_build.py` verifies the frozen441 module, its owner,391 schema, controls result and a concrete Root release before importing441. It wraps the actual function objects to count calls. It records each successful `read_pinned` and retains the first returned bytes without reopening the twelve input files. A build-scoped Python audit hook permits read opens only for the context graph, twelve fixed inputs, accepted audit and its own output files; write opens only for the declared new build directory. This is an execution trace and boundary check for the reviewed standard-library code, not a general sandbox claim.

The wrapper invokes the real build exactly once. It then checks the sealed output owner/readback, reconstructs the emitted field mappings independently from those retained raw bytes, and compares exact JSON types/bit strings/order. No bridge projector is called again, no model is instantiated, and the original twelve files are not independently reopened. Independent JSON parsing of retained bytes is reported separately from the bridge's one decode.

## Realize

Both output directories must be new under repo/data and distinct. The release is engineering launch authority, not bundle state.

`run(release_path)` checks identities, imports only441 plus its stdlib/391 dependencies, reserves the independent receipt directory, installs counters and the build-only read/write hook, and calls the build once. Independent validation checks all39 fixture identities/orders, original sparse node coordinates and P7/O5,33 Timer configurations/private origins, Character and pre-prepare scalar fields, complete clock and primitive physical sequence, five/fourteen-key ABI, actual before/after read trace and output owners. All input mapping work uses first-read memory bytes. First unexpected failure is recorded; no retry or repair occurs.
