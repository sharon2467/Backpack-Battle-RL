## 2. Design

### Definition and phase association

Let the validated source clock have activation checkpoint H and ordered rows r[1..n]. Existing clock validation already checks strictINT counters, exact physics60 delta bits, actual idle deltas, contiguous physics advancement, idle progression, complete order, caps and no trailing records. Retain it unchanged.

Cleanup C is written at the original `Core/Game.gd::combatEndDeferred` end marker, after the rule-derived deferred cleanup body. Its original three-field DTO remains `(physics_frame,idle_frame,is_in_physics_frame)` with strict types. Associate C to the unique already-recorded signal row of the matching kind and actual counters; the signal precedes that frame's internal/ordinary work. Record the existing row ordinal as control-only `cleanup_anchor_pass`. A cleanup exactly in the original activation idle-tail checkpoint, before any pass, may use ordinal0 only when the checkpoint and idle phase match exactly. Missing, duplicate, mismatched-phase or unrecorded intermediate-frame association fails closed. No invented row or counter normalization is allowed.

For a row j after that anchor define N(j) as the number of actual physics rows strictly after the cleanup anchor with physics_frame>C.physics_frame. Every such row must also satisfy the existing contiguous source clock rule; do not count a repeated current-physics signal, an idle, or a frame-number jump. Eligible(j) means r[j] is idle and N(j)>=2. The unique legal terminal row is j*=the first eligible row in the actual sequence. The clock ends exactly at j*. N(j*) may be2,3,8 or another bounded count. The final idle is sampled preinternal, so its internal/ordinary work must not run before freezing.

An idle with0 or1 future physics is retained and is ineligible. Multiple idles may occur without a physics increment; multiple physics may occur without an idle. The first eligible idle wins in all cases. A later idle with N>=2 is invalid if any earlier actual eligible idle existed. EOF before j*, any record after j*, or skipping the first eligible callback cannot become success.

### Producer mechanism: bounded O(1) observation bookkeeping

Keep the existing clock bytes/counters/order and original callback connections unchanged. Add only a private primitive tail tracker: cleanup anchor ordinal, cleanup phase/counters, observed future-physics count, and one immutable first-eligible latch `(ordinal,physics,idle,count)`. This is not a new gameplay listener, Timer or schedule. Track a row only after its original clock append/flush succeeds. `source_mark_cleanup` captures the already-recorded pass association without adding a clock row. Clock diagnostics use their separate bounded control writer and never increment the four-channel shared sequence.

At the first eligible recorded idle, latch immediately in `clock_pass`, before the later close/emit branch can be bypassed. `clock_idle_signal` must close on this exact latch, same current counters and ordinal, or fail. Any subsequent pass/callback with an outstanding eligible latch is a missed-first-cut failure; it cannot silently replace the latch. Preserve all earlier failure checks and primary-error precedence. This additional state makes overshoot detectable in the producer; the terminal schema must independently derive j* from the complete raw clock rather than trusting this latch or an `is_first=true` flag.

The sink then performs the existing sequence: close clock -> write final SOURCE snapshot -> close UI -> set source_window_complete/closed -> unique synchronous dedicated signal -> actual NIL return observed -> exact callback ack -> finalizer actual BOOL -> FINALIZED. The collector once guard is set before the existing full snapshot. Finalization serializes frozen primitive DTOs only. No second getStats/snapshot, frame/deferred hop, business callback, RNG call, new GUI action or event retention is introduced. Original SceneTree idle subscribers, flags/order and Node internal processing are not modified.
